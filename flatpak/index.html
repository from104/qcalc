QCalc — Flatpak repository

Version 0.13.5 · published 2026-09-17 · GPG-signed · x86_64

QCalc is a keyboard-friendly, screen-reader-accessible multi-purpose calculator (standard, unit, currency, radix, formula) in 10 languages. Source and other packages: github.com/from104/qcalc.

Install

flatpak install --user https://from104.github.io/qcalc/flatpak/qcalc.flatpakref

This adds the repository and installs the app. Later versions arrive through the normal flatpak update.

Add the repository only

flatpak remote-add --user --if-not-exists qcalc https://from104.github.io/qcalc/flatpak/qcalc.flatpakrepo
flatpak install --user qcalc io.github.from104.qcalc

Run

flatpak run io.github.from104.qcalc

Notes

  • Screen reader users: the WebKit UI inside the Flatpak sandbox is currently not exposed to AT-SPI. Use the .deb, .rpm, Snap or AppImage instead.
  • The repository keeps the two most recent versions. The GPG public key is qcalc.gpg (embedded in the .flatpakref).
