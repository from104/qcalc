## Журнал изменений

Все заметные изменения этого проекта записаны в этом файле.

Формат основан на [Keep a Changelog], и этот проект следует [Семантическому Версионированию].

## [0.13.1] 2026-08-18

### Изменено

- Унифицированное имя пакета QCalc (на Windows удалите старую запись «Q Calc»)

### Добавлено

- APK для Android в каждом выпуске

### Исправлено

- Запуск пакета Snap исправлен ([#117](https://github.com/from104/qcalc/issues/117))
- Уведомления об обновлении из 0.12.x видны (Windows, AppImage)
- Установщик Windows удаляет остатки Electron
- AppImage больше не завершается сразу в Wayland (Linux)
- Исправлено неправильное выделение поля результата
- Масштабирование текста рабочего стола применяется к размеру окна (Linux)
- Подписи клавиш больше не выходят за пределы кнопок
- Удалено требование разрешения на звук для Flatpak

### Известные проблемы

- Программы чтения с экрана не видят интерфейс в сборке Flatpak — ограничение песочницы. Используйте `.deb`, `.rpm` или AppImage ([#113](https://github.com/from104/qcalc/issues/113))
- Чтение буфера обмена может не работать в Linux

## [0.13.0] 2026-08-09

### Изменено

- Настольное приложение перейдено с Electron на Tauri 2
- Автоматическое обновление полностью активировано в Tauri
- Добавлена миграция истории и онбоардинг
- Native Wayland по умолчанию ([tauri#13749](https://github.com/tauri-apps/tauri/issues/13749) / [tauri#3117](https://github.com/tauri-apps/tauri/issues/3117))
- Увеличен размер окна по умолчанию (352×604 → 480×756)

### Добавлено

- Добавлены 2 новых языка (португальский и русский) — всего 10
- Объявление результатов программой чтения с экрана в Linux
- Объявление ошибок формул
- Отмена удаления записей
- Доступность с клавиатуры для вкладок, поля формулы и переключателя памяти
- Цвета темы с контрастом WCAG AA

### Исправлено

- Улучшена поддержка программы чтения с экрана
- Форматирование чисел по языку
- Исправлены градусы в калькуляторе формул, классификатор ошибок и подстановка заполнителей
- История записей соблюдает максимальное количество после восстановления
- Исправлено зависание приложения при запуске на рабочем столе
- Улучшены размер окна Tauri/Linux, отображение текста, значки, упаковка Flatpak и Snap
- Исправлено открытие справочных страниц на португальском и русском языках
- Исправлены метки на корейском языке

### Известные проблемы

- Пакет Snap не запускается ([#117](https://github.com/from104/qcalc/issues/117))
- Программы чтения с экрана не видят интерфейс в сборке Flatpak — ограничение песочницы. Используйте `.deb`, `.rpm` или AppImage ([#113](https://github.com/from104/qcalc/issues/113))
- Проверка программы чтения с экрана в Linux неполная (звучание, наведение, буфер обмена, CSP)

Для получения информации о предыдущих версиях, пожалуйста, перейдите [сюда](https://github.com/from104/qcalc/blob/main/CHANGELOG.md).
